
# Flora Endémica de Canarias 🌿

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una página web dedicada a la flora endémica de las Islas Canarias, utilizando **HTML5 y CSS**.

El objetivo principal es dar a conocer algunas de las especies vegetales únicas del archipiélago canario y destacar su importancia para la biodiversidad y la conservación del medioambiente.

Para desarrollar el diseño visual de la página, se ha utilizado como inspiración una plantilla floral de Wix, adaptando su estilo a la temática de la naturaleza canaria.

**Plantilla utilizada como inspiración:** [Flower Shop - Wix](https://es.wix.com/website-template/view/html/1991?originUrl=https%3A%2F%2Fes.wix.com%2Fwebsite%2Ftemplates%3Fcriteria%3Dflower&esi=8d317dee-c27e-4927-b3b1-a3b5bac4ced0)

## Comenzando 🚀

Estas instrucciones permiten obtener una copia del proyecto en funcionamiento en tu ordenador para visualizarlo, modificarlo y realizar pruebas.

## Pre-requisitos 📋

Antes de comenzar, necesitas disponer de las siguientes herramientas:

- **Un navegador web:** Google Chrome, Firefox, Microsoft Edge u otro navegador actualizado.
- **Un editor de código:** se recomienda [Visual Studio Code](https://code.visualstudio.com/).
- **Git:** necesario únicamente si deseas descargar el proyecto mediante un repositorio.

No es necesario instalar frameworks ni dependencias adicionales, ya que el proyecto está desarrollado con HTML y CSS.

## Instalación 🔧

Sigue estos pasos para ejecutar el proyecto en tu ordenador.

### 1. Descargar el proyecto

Si el código está alojado en GitHub, abre una terminal y ejecuta el siguiente comando, sustituyendo la URL por la de tu repositorio:

```bash
git clone (https://github.com/aleso-rincon/project-1-LND)
```

### 2. Acceder a la carpeta del proyecto

```bash
cd prototipo-1-entrega-1-css-html
```

### 3. Abrir el proyecto

Abre la carpeta con Visual Studio Code o con el editor que prefieras.

Si utilizas Visual Studio Code, puedes ejecutar:

```bash
code .
```

### 4. Ejecutar la página web

Busca el archivo `index.html` y ábrelo con tu navegador web.

También puedes utilizar la extensión Live Server de Visual Studio Code para visualizar los cambios automáticamente mientras editas el código.

### 5. Comprobar el resultado

Una vez abierta la página, podrás visualizar el diseño, consultar los textos y recorrer las secciones disponibles.

Si modificas los archivos HTML o CSS, guarda los cambios y actualiza el navegador para comprobar el resultado.

## Ejecutando las pruebas ⚙️

Las pruebas se realizan principalmente de forma manual, comprobando que la página funcione correctamente y que el contenido se visualice como se espera.

Se recomienda verificar los siguientes aspectos:

- Que la página principal se cargue correctamente.
- Que las imágenes de las plantas se muestren sin errores.
- Que los enlaces funcionen correctamente.
- Que los textos sean legibles y estén bien organizados.
- Que el diseño se adapte a diferentes tamaños de pantalla.
- Que los estilos CSS se apliquen correctamente.

### Pruebas de funcionamiento end-to-end 🔩

Se pueden realizar las siguientes pruebas:

- Abrir la página principal.
- Recorrer las distintas secciones.
- Comprobar que las imágenes se carguen correctamente.
- Verificar que los enlaces lleven a sus destinos.
- Revisar la visualización en ordenadores, tabletas y móviles.

**Ejemplo:** abrir el archivo `index.html` y comprobar que la información sobre la flora endémica de Canarias aparece correctamente.

### Pruebas de estilo de codificación ⌨️

Para ello, se pueden utilizar las siguientes herramientas:

- **W3C HTML Validator:** permite comprobar la estructura del código HTML. [Acceder al validador](https://validator.w3.org/).
- **W3C CSS Validator:** permite detectar errores en las hojas de estilo. [Acceder al validador](https://jigsaw.w3.org/css-validator/).
- **Herramientas de desarrollo del navegador:** permiten inspeccionar elementos, revisar estilos y detectar errores visuales.

**Ejemplo:** validar el archivo HTML para comprobar que las etiquetas estén correctamente organizadas y que el documento no presente errores de estructura.

## Despliegue 📦

Para publicar la página web en Internet, se puede utilizar una plataforma de alojamiento de sitios estáticos.

Algunas opciones son:

- **GitHub Pages:** permite publicar páginas web directamente desde un repositorio de GitHub.
- **Netlify:** facilita el despliegue de sitios web estáticos.
- **Vercel:** permite alojar proyectos web y gestionar sus publicaciones.

Para desplegar el proyecto mediante GitHub Pages:

1. Sube los archivos del proyecto a un repositorio de GitHub.
2. Accede a la configuración del repositorio.
3. Busca la sección **Pages**.
4. Selecciona la rama que contiene los archivos de la página.
5. Guarda los cambios y espera a que finalice la publicación.

Una vez completado el proceso, GitHub Pages proporcionará una dirección web desde la que se podrá visitar el proyecto.
